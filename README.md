# reactfirstapp

An expense tracker, and my first React app. Add expenses, filter them by
year, and see monthly spending as a bar chart.

- Components for the expense list, items, form and filter
- State lifted up to share new expenses between the form and the list
- A simple chart built from plain components, no chart library

**Stack:** React 18, Create React App

## Run it

```bash
npm install
npm start
```
